# Лабораторная работа №3: Проектирование архитектуры информационной системы

**Цель работы:** Изучить принципы проектирования архитектуры веб-приложений, спроектировать взаимодействие между компонентами системы с учетом индивидуальной особенности (асинхронных уведомлений) и подготовить структуру проекта для дальнейшей разработки.

---

## 1. Архитектура приложения

Для системы учета библиотечного фонда выбрана **трехуровневая веб-архитектура (3-tier)**:
* **Frontend (Клиентская часть):** Веб-интерфейс для взаимодействия пользователей с системой.
* **Backend (Серверная часть):** Главная логика приложения, которая принимает и обрабатывает входящие запросы.
* **Database (База данных):** Хранилище для надежного размещения данных о книгах, читателях и выдачах.

---

## 2. Компоненты системы

Серверная часть разделена на следующие компоненты:
* **Маршрутизация и Контроллеры:** Принимают запросы от пользователей и запускают соответствующие процессы.
* **Сервисы:** Реализуют бизнес-правила системы (например, проверку возможности выдачи книги читателю).
* **Репозитории:** Отвечают за прямое взаимодействие с базой данных (выполнение SQL-запросов).
* **Модуль уведомлений:** Отдельный компонент, отвечающий за формирование и отправку сообщений читателям.

---

## 3. Взаимодействие компонентов

Последовательность обработки действия пользователя (например, выдачи книги):
1. Пользователь заполняет форму на сайте.
2. Веб-интерфейс отправляет запрос на сервер (Backend).
3. Контроллер передает задачу в сервис бизнес-логики.
4. Сервис сохраняет данные через репозиторий в базу данных.
5. При необходимости подключается модуль уведомлений и отправляет сообщение читателю.
6. Сервер возвращает ответ на сайт, и пользователю отображается результат.

---

## 4. Индивидуальная особенность предметной области

В системе выделена нетиповая особенность - **автоматическое асинхронное уведомление читателей о сроках возврата книг или возникшей просрочке (Email/Push)**. Отправка выполняется в фоновом режиме, что исключает задержки в работе пользовательского интерфейса.
